## 📖 Sobre el Proyecto

Este repositorio contiene un **Hub Interactivo de Ciberseguridad** orientado a la formación académica y profesional en el ecosistema de seguridad 2024-2025. Recopila los **6 dominios funcionales principales**, más de **40 certificaciones** reconocidas por la industria, las **especializaciones emergentes** y un **glosario técnico** de más de 45 términos.

Diseñado para servir como:
- 📚 **Material de estudio académico**.
- 🗺️ **Guía de carrera** para profesionales de ciberseguridad.
- 🎯 **Referencia rápida** de certificaciones y marcos.
- 🧭 **Mapa visual** de dominios Blue/Red/Purple Team.

## 🚀 Especializaciones Emergentes

<details>
<summary><strong>🏭 OT / IoT / SCADA — Infraestructuras Críticas</strong></summary>

- **Funciones:** Analista de red industrial → Ingeniero de ciberseguridad para plantas de energía, agua y manufactura.
- **Certificaciones:** GICSP, GRID, CSSA, ISA/IEC 62443.
- **Marcos:** ISA/IEC 62443, NIST SP 800-82.

</details>

<details>
<summary><strong>🧠 Seguridad en IA y Machine Learning</strong></summary>

- **Funciones:** LLM Red Teaming, defensa contra Prompt Injection, envenenamiento de datos.
- **Marcos:** OWASP Top 10 for LLM, MITRE ATLAS, NIST AI RMF.

</details>

<details>
<summary><strong>⚛️ Criptografía Post-Cuántica</strong></summary>

- **Funciones:** Migración a algoritmos resistentes a computación cuántica.
- **Estándares:** FIPS 203 (ML-KEM), FIPS 204 (ML-DSA), FIPS 205 (SLH-DSA), CNSA 2.0.

</details>

<details>
<summary><strong>🌐 Otras Tecnologías Especializadas</strong></summary>

- **Blockchain / Web3:** Auditoría de Smart Contracts.
- **Seguridad Vehicular:** ISO/SAE 21434, UNECE R155/R156.
- **Seguridad Espacial:** NIST IR 8270, Space ISAC.
- **Redes 5G / 6G:** 3GPP, GSMA FS.11, NIST 5G Cybersecurity.

</details>

## 📚 Glosario (muestra)

<details>
<summary><strong>Ver 10 términos clave (de +45)</strong></summary>

| Término | Categoría | Definición |
|---------|-----------|------------|
| **APT** | Amenazas | Advanced Persistent Threat. Actor con recursos avanzados que mantiene acceso prolongado. |
| **SIEM** | Herramientas | Security Information and Event Management. Centraliza logs y correlaciona eventos. |
| **EDR** | Herramientas | Endpoint Detection and Response. Monitoriza y responde a amenazas en endpoints. |
| **MITRE ATT&CK** | Marcos | Base de conocimiento de TTPs usados por adversarios reales. |
| **Zero Trust** | Arquitectura | Modelo que asume que ninguna entidad es confiable por defecto (NIST SP 800-207). |
| **PQC** | Criptografía | Post-Quantum Cryptography. Algoritmos resistentes a ataques cuánticos. |
| **SAST** | DevSecOps | Static Application Security Testing. Análisis de código sin ejecutarlo. |
| **CVE** | Vulnerabilidades | Common Vulnerabilities and Exposures. Identificador único de vulnerabilidades. |
| **YARA** | Forense | Lenguaje de reglas para identificar malware por patrones. |
| **NIS2** | Regulación | Directiva europea de ciberseguridad para sectores críticos. |

</details>

👉 [Ver glosario completo en el dashboard](https://TU-USUARIO.github.io/ciberseguridad-hub/dashboard.html)

## ⚙️ Cómo Desplegar en GitHub Pages

### Paso 1: Crear el repositorio

```bash
git init ciberseguridad-hub
cd ciberseguridad-hub
git remote add origin https://github.com/TU-USUARIO/ciberseguridad-hub.git
```

### Paso 2: Añadir los archivos

```bash
# Copia README.md y dashboard.html a este directorio
git add README.md dashboard.html
git commit -m "feat: dashboard inicial de ciberseguridad"
git push -u origin main
```

### Paso 3: Activar GitHub Pages

1. Ve a **Settings** → **Pages** en tu repositorio.
2. En **Source** selecciona **Deploy from a branch**.
3. Selecciona **Branch: main** y carpeta **/ (root)**.
4. Guarda y espera ~1 minuto.

Tu dashboard estará disponible en:
```
https://TU-USUARIO.github.io/ciberseguridad-hub/dashboard.html
```
